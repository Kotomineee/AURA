# AURA 0.1.2 

O **AURA** é um projeto pessoal de assistente virtual desenvolvido para facilitar o controle do computador por meio de comandos de voz, permitindo executar tarefas do dia a dia de forma simples e prática.

A ideia é criar um assistente que consiga interpretar comandos e interagir com o sistema operacional e com aplicativos, automatizando ações que normalmente precisariam ser feitas manualmente.

### Objetivo do projeto

O principal objetivo é desenvolver uma aplicação funcional que permita controlar diferentes recursos do PC, como:

- Controle Total do Computador
- Controlar aplicações e automação do PC.
- Executar ações no sistema por comandos de voz.
- Permitir o controle remoto de determinadas funções pelo celular.
- Expandir gradualmente as funcionalidades conforme o desenvolvimento.

### Desenvolvimento

O projeto está em fase de desenvolvimento e será construído de forma gradual, começando pelas funcionalidades mais básicas e avançando para integrações mais complexas.

Além de criar uma ferramenta útil para o meu próprio uso, também pretendo utilizar o AURA como uma oportunidade para aprimorar meus conhecimentos em Python, automação, integração de sistemas e organização de código.

O desenvolvimento conta com o auxílio de ferramentas de inteligência artificial, mas também envolve análise, revisão, testes e ajustes manuais para entender melhor o funcionamento da aplicação e melhorar sua estrutura.

### Status
